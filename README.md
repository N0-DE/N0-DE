I am a software engineer passionate about transforming complex engineering challenges into clean, demonstrable software. My portfolio ranges from **real-time computer vision pipelines** running vehicle tracking algorithms to **production-grade enterprise ERP suites** and **biometric payroll automation systems** handling mission-critical business transactions.

<details>
<summary><b>💡 Click to Expand: Core Engineering Philosophy & Architectural Principles</b></summary>
<br/>

1. **Offline-First Resilience**: Software must deliver full local utility even during total network downtime. Applications default to embedded storage engines (SQLite) with automatic synchronization and multi-terminal database failover (PostgreSQL).
2. **Deterministic Data Integrity**: Strict validation via Pydantic schemas and TypeScript interfaces before database persistence; double-entry accounting models ensure ledgers balance to the exact cent.
3. **Applied AI Over Hype**: Machine learning models (YOLO, Gemini) are integrated directly into operational pipelines to automate measurable bottlenecks—such as line-crossing traffic census, OCR billing credit locks, or farmer voice telemetry.
4. **Lean Systems Over Heavy Runtimes**: Preferring lightweight native shells (Tauri v2 in Rust, Flet / Flutter engines) over resource-intensive desktop web wrappers.

</details>
